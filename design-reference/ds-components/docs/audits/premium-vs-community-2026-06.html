R·C

Founder visit signal — „ביקרתי כאן…"

CANDIDATE-NEEDS-JUSTIFICATION · run explicitly against the "no time-stamped framing" LOCK
Effort 3–4h Risk · Medium

A per-producer line stating that Sapir personally visited — the strongest accountability signal a curated directory can carry. But it sits one inch from a brand LOCK, so it ships only in a constrained form. The justification is below; read it before the mockup.

  LOCK check: is this accountability, or periodical-stamping?

The LOCK: no time-stamped periodical framing — "ISSUE 01", "SPRING 2026" — because Mehamakor is a magazine in voice, not a dated edition you subscribe to.

The distinction that clears it: a periodical stamp dates the whole publication ("this is the spring edition"), framing the site as perishable content. A founder-visit line dates one relationship ("I, Sapir, stood in this kitchen") — it is bound to a single producer, accountability metadata, not an edition marker. It says who vouches and that they showed up, which is the curated-approval DNA, not when this issue dropped.

The constraint that keeps it clear: ① attach to the producer story, never the masthead/home; ② phrase as a personal act, not a publication date — „ביקרתי כאן" + season, never a bare "02/2026" chip; ③ no recency decay UI (no "visited 4 months ago" countdown — that re-introduces perishability). Ship constrained, with Sapir's sign-off.

  Reconciling R-C and R-D — no double date-stamp

These two must not collide. R-C puts a founder-visit line on the producer page — seasonal, never dated, sign-off-gated. R-D explains the „מאומת בלבד" chip at the filter level — purely qualitative ("selected personally, checked before listing"), with no date and no per-visit claim. My round-1 R-D carried a home date-chip („ספיר ביקרה · חורף 26'") — that re-tripped the very time-stamp LOCK R-C is built to honor, so it's removed. Dates live nowhere on home; the only time signal is R-C's seasonal phrasing, on the producer story, behind Sapir's sign-off.

Brand-LOCK check

  • No gradient orbs / blur / glassmorphism: the ambient is a single flat grain at the same #F5F0E8 — never pure white, never a gradient. The warmth-token's explicit constraint, honored.
  • Filters stay filters: the explainer touches only the „מאומת בלבד" trust chip — never „טבעוני"/„ללא גלוטן"; dietary facts aren't vouched for.
  • Phosphor regular, no Lucide, no duotone: chip set and info glyph unchanged in weight.
  • No date on home: the round-1 home date-chip is removed (see reconciliation above); the explainer is qualitative only. Dated/visit signals live solely on the producer page via R-C — ADR-019 colors (gold + --fg-muted) only, no new semantic tokens.
