The shared system — texture before treatment

All three directions ride the same depth stack. Nothing here is new — it extends what already shipped on /about (QA rounds 4–5): film grain, tonal steps, hairline borders. Photography is the fourth layer, not a replacement.

Rules — texture & depth

  • 1One grain layer, everywhere. Same SVG recipe already live on /about, alpha 0.035 — and it sits over the photography too, so images and cream share the same air.
  • 2Tonal steps, not shadows. --background → --background-alt is the only sectioning device. Depth = overlap + step + mat. Zero new shadow tokens.
  • 3One scrim recipe. Text over photos sits on the production overlay family rgba(46,74,46,…), bottom-up fade. Never a full-frame darken.
  • 4Motion = Ken Burns only. 22s drift, scale ≤ 1.06, on hero slots marked KB. prefers-reduced-motion → static frame, scrim unchanged — reads intentional. #1053 layer untouched.

Rules — sourcing & performance

  • 5Subjects: licensed בתי עסק only (BRAND §7). Alt-text pattern "{שם בית העסק} — {קטגוריה}, {עיר}". No home-kitchen / neighbor framing in any caption or alt.
  • 6Look: Kinfolk + Natoora (BRAND §5) — natural light, warm, editorial. Not glossy stock, not marketplace.
  • 7Cloudinary contract: f_auto,q_auto,w_auto,dpr_auto · hero eager + fetchpriority=high · all else loading="lazy" · every slot is an aspect-ratio box → zero layout shift.
  • 8AA floor: cream on the scrim text-zone ≥ 7:1 worst-case (measured against a blown-highlight frame). Numbers per direction in the notes column.
