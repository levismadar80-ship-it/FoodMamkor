Three states — שלושה מצבים

Same chip · two tooltips · one no-chip

States 1 & 2 are the same chip — identical glyph, identical word מאומת — differing only in tooltip copy. State 3 is no chip, ever, and is never a negative marker. Tooltip strings are Sapir-locked (MEH-758); {date} is the real submission-and-review date in d.m.yyyy.

When. Exempt categories, no document filed — the baseline path. No chip. No icon. No placeholder. The only mark is the calm מוצהר line in the shared trust block (§00·Q1·C). Absence of a chip is never rendered as a negative.

The equality test. A מוצהר page must never read as missing or lesser. We pass it by structure, not apology: the chip is an additive mark for an extra document — מסמך נוסף, לא אמון נוסף — so its absence carries no deficit. Forbidden on every surface: "unverified", greyed/ghost chips, lock icons, "pending", any comparative "vs verified" framing.

3 rules this spec commits to

  1. 1One glyph, surface-scaled. The locked seal is identical everywhere; only word-vs-icon changes with surface density (chip on single surfaces, seal on lists). Recognition stays constant; noise doesn't.
  2. 2The badge is additive. מסמך נוסף — לא אמון נוסף. It marks an extra filed document, not extra trustworthiness. This framing is what lets absence be neutral.
  3. 3Equality by structure. The trust slot exists on every page; verified fills it with a chip, declared with a calm locked line. No page is built to display a lack.

Anti-patterns — forbidden on every surface

  • ✕No negative marker for מוצהר. No "unverified", no greyed/ghost chip, no lock icon, no "pending", no comparative "vs מאומת". Declared shows no chip — full stop.
  • ✕No hover-only tooltip. Touch must reach it by tap/long-press. And no AI-slop: Phosphor regular only, no emoji, no new colors, no second accent — gold is the only badge color.
