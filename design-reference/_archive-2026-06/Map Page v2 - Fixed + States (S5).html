This iteration's fixes

✓Logo — canonical wordmark מהמקור, 6 letters in Frank Ruhl Libre. No niqud, no Latin tagline, no flower glyph. Desktop + mobile pill identical.
✓Navbar v5 embedded as-is: חיפוש filled primary · הוסיפו עסק outlined · כניסה לחשבון text. One composition, no per-page variants. Links גלו · מפה · אודות.
✓Photos back — list cards carry a square business photo; map markers are circular photos. Category-colour circle used only for the cluster bubble and the photo-less fallback.
✓Glyph tier quarantined — hand-drawn category glyphs appear only inside filter pills (and the one fallback marker). Never on cards, never mixed with Phosphor on the same surface.
✓CTA — two variants: WhatsApp primary and phone (התקשרי) primary. Exactly one primary + לדף המלא link. Never three buttons.
✓Heart removed entirely (feature doesn't exist). פעיל היום replaced by a neutral hours line in --fg-muted, no status colour.

System & states

✓Units & ranges — distances read ק״מ with the gershayim; hours render as a single LTR-isolated range (08:00–18:00, never reordered). No Latin "km".
✓Handoff dir note — every numeral, time, time-range and distance is wrapped in .numeric (direction: ltr; unicode-bidi: isolate). Devs must keep that wrapper on bidi-sensitive runs so the en-dash and colons don't flip inside RTL.
✓Pills — one selected affordance only: filled primary. No ✕ pattern. Disabled pill = dashed + dimmed + 0 count, not tappable.
✓Sheet — locked at 45vh rest, visible drag handle, two snap points (45vh ↔ expanded). Map interactive at rest; list scrolls only when expanded.
✓States — (a) location-denied → בחרי עיר + city search, distances dropped; (b) disabled filter → 0-business empty state; (c) loading skeleton mirroring card rhythm.
✓Tokens — colours resolve to v1.0 primitives or color-mix() of them; photo placeholders are token-derived gradients. Borders 1px --border; pills/CTAs 9999px; single shadow token.
✓Copy — feminine voice, בית עסק never יצרן, zero Unicode emoji, no דירקטורי / "marketplace" / אוכל ביתי. RTL logical properties throughout; touch targets ≥ 44px.
