Type — Hebrew-corrected scale

Per Spiekermann + Frere-Jones: Hebrew descenders (ל ך ץ) need clearance — line-heights start at 1.05, never lower. Hebrew does not tighten — tracking is 0em or positive, never negative. Cormorant Garamond has no Hebrew glyphs; the italic family falls back to Frank Ruhl Libre italic — documented in --font-italic.

Spacing — 8px soft baseline grid

Locked 21 May 2026. Eight, sixteen, twenty-four — never twelve, never twenty. Vignelli's editorial discipline meets Tailwind's defaults; Hebrew line-heights at 24/32px land cleanly on the grid. Soft means elements need not snap; values must.

04

State tokens — seven, no overlap

New in v1.0 (Brad Frost). Each interactive element resolves exactly one state per pointer phase. Save / like never uses red — green or gold only (Ive). Hover never lifts via shadow — that is a SaaS pattern, not a magazine.

--state-default Default
שמרי

Base. No transform, full opacity, --border outline.

--state-hover Hover
שמרי

Image scale 1.02 or caption underline (1px --green). No shadow lift.

--state-active Active
שמרי

Opacity 0.95 or scale 0.98. Mobile press feedback.

--state-selected Selected
שמרי

2px solid --green. Loud — use sparingly (filter, pinned item).

--state-visited Visited
שמרי
ראית

Desaturate 20 % + small italic caption "ראית". Never purple.

--state-disabled Disabled
שמרי

Opacity 0.5 · cursor: not-allowed. No pointer events.

--state-focus Focus
שמרי

2px ring --focus-ring · offset 2px. Keyboard-only via :focus-visible.

— Composition & precedence
  1. disabled wins always. If disabled, no other state applies — no hover, no focus.
  2. active > hover. Pressing supersedes pointing; same element cannot show both transforms.
  3. focus composes with all non-disabled states. The ring is keyboard accessibility — it must coexist with hover and selected.
  4. selected composes with hover via additive border thickening only — never two simultaneous transforms.
  5. visited is a content state, not a pointer state. It composes with any pointer state below it.
05

Voice — Hybrid (Brand Hub v1.1)

UI strings are gerund or plural — neutral by default. Brand narrative (founder story, /about, editorial) is feminine — singular "גלי, צרי" allowed. The Hero is treated as UI, not narrative.

Do — UI surfaces

  • ●טוענת עסקים טריים…Loading — gerund
  • ●גלי עסקיםCTA — plural-imperative, OK in UI
  • ●הוסיפי עסקAction button — plural OK
  • ●לא מצאנו עסקים שתואמים — נסי קטגוריה אחרתEmpty state — specific guidance, no emoji (Kare)
  • ●משהו השתבש, נסי שובError — feminine plural

Don't

  • ✕טוענ/ת…Slash form is clunky and reads as draft copy
  • ✕המשתמש שלךMasculine-only — excludes audience
  • ✕פלטפורמת מסחר"Marketplace" framing — LOCK violation
  • ✕ISSUE 01 · SPRING 2026Time-stamped framing — we don't publish issues
  • ✕100+ עסקים (actual: 30)Overpromise — magazine credibility lost
— Lock rules · non-negotiable
  • ✕"שכנות מבשלות מהבית" / "מהמטבח של השכן" / "אוכל ביתי" — illegal in IL without licensing.
  • ✕"יצרן" / "יצרנית" — always בית עסק / בעלת עסק.
  • ✕"marketplace" / "פלטפורמת מסחר" anywhere in UI or marketing.
  • ✕The word "מגזין" in UI surfaces — only in /about narrative.
  • ✕Time-stamped framing ("ISSUE 01", "SPRING 2026") — we don't publish issues.
  • ✕Partial category lists; overpromise on counts; "אמיתי" as Healthy Halo buzzword (contextual only).
  • ✕Red heart fill on save / like — green or gold only.
  • ✕Gradient orbs, blurred backgrounds, glassmorphism — app aesthetic, not magazine.
06

RTL & numerals

Hebrew is the default direction. Latin numerals are universal — kilometres, grams, shekel. The .numeric class isolates LTR runs and applies tabular + lining figures so prices and distances align in card grids.

Do

  • ●1.8 kmLatin numerals + Latin unit · scannable
  • ●500gGrams, lowercase, no space
  • ●₪78ISO 4217 sign · before digits
  • ●+972 50 123 4567E.164 in display contexts
  • ●ms-* · me-* · start-* · end-*Logical properties only — never ml/mr
  • ●ישראל — ישרNBSP + em-dash + space

Don't

  • ✕1.8 ק"מHebrew abbreviation — bidi switch, slower scan
  • ✕500 גרםSpelled-out unit — magazine ≠ poster
  • ✕78 ש"חUse ₪ — the sign exists for a reason
  • ✕letter-spacing: -0.02em on HebrewHebrew doesn't tighten — only loosens
  • ✕line-height: 0.95 on HebrewDescenders ל ך ץ collide — broken
  • ✕ml-4 / mr-4 / left: 0 / right: 0Direction-breaking — use logical props
