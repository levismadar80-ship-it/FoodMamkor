## Methodology note on citations

Because WebSearch returns excerpted snippets rather than full pages, every claim in the main report is sourced to either:
(a) **Page title** — these are reliable (returned by search engine from the rendered `<title>` tag), or
(b) **Meta description / search snippet** — also reliable but condensed, or
(c) **Third-party profile** (Wikipedia, EIB, Food Tank, Times of Israel, USV/AVC blogs) — secondary source, lower confidence than first-party.

Claims about **homepage section order, map placement, listing-card structure, and conversion-flow click count cannot be verified from WebSearch alone** — those require live page-render evidence. The main report flags those claims as `[unverified-from-snippets]` and lists them as open questions for a follow-up session with browser access.
