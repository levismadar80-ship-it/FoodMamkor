# Discovery anti-pattern audit — reader journey vs. industry checklist (MEH-1077)

> **Date:** 2026-07-10 · **Scope:** consumer (reader) surfaces only — homepage → category → /producers → /map → /search → /producer/[slug] → WhatsApp CTA → /events → consumer auth touchpoints.
> **Excluded:** producer dashboard (MEH-999), admin, register-flow internals.
> **Method:** three lenses per surface — (A) NN/g heuristics, (B) Baymard directory families, (C) 12-item directory anti-pattern checklist (compiled 09/07). CONFIRMED = code (file:line) **and** screen (Playwright, 375px + desktop, local `next start` + seed DB). One of two = SUSPECTED.
> **Environment:** local production build (`next start`, port 3000) against local FastAPI + Postgres seeded via `backend/seed_data.py` (5 producers, 18 categories). Map tiles gray in screenshots (OSM egress blocked in the CC sandbox — MEH-360 class); markers/chips/UI render fully. Machine-readable interaction log: `screenshots/2026-07-meh1077/evidence.json`.
> **Audit only — zero product-code changes.** Severity per docs/BUG_SEVERITY.md (SEV-1..4), UX-impact reading.
