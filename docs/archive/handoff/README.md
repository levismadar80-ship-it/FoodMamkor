# HANDOFF archive

`HANDOFF.md` keeps only the last ~7 days of session state (ADR-035, MEH-2344). Older sections live here.

| File | What it holds |
|---|---|
| [`HANDOFF-until-2026-10-21.md`](./HANDOFF-until-2026-10-21.md) | A **verbatim, full-file** copy of `HANDOFF.md` as it stood at `171781166` on `staging` (13,716 lines, every section from the project's start to 2026-10-26). |

**Old line citations.** Many files cite `HANDOFF.md:NNNN`. Every such citation written before 2026-10-26 resolves at the **same line number** in `HANDOFF-until-2026-10-21.md`, because that copy is the whole file, not a slice. Note that it also repeats the 21/10–26/10 sections that are still live in `HANDOFF.md`. That duplication is deliberate: removing it would shift every line number.

**From now on**, sections that age out of `HANDOFF.md` move into one file per month, `YYYY-MM.md`, via `scripts/docs/archive_handoff.py` (MEH-2346). That file's sections are verbatim and newest first, the same order as `HANDOFF.md`.

Archives are frozen. Do not edit them. A correction goes in a new `HANDOFF.md` section or in the doc that owns the fact.
