## תיקון 1 — החלפת "יצרן" בכל הפרויקט

החלף את כל המילים הבאות בכל הקבצים (frontend + backend):

```
"יצרן"        → "בית עסק"
"יצרנים"      → "בתי עסק"  
"יצרנית"      → "בעלת עסק"
"producer"    → "business"  (בשמות משתנים חדשים — לא בDB!)
"producers"   → "businesses" (בטקסטים בלבד — לא בDB!)
```

⚠️ חשוב — אל תשנה בDB ובAPI:
- שמות עמודות בDB נשארים: `producers`, `producer_id` וכו'
- API endpoints נשארים: `/producers`, `/producers/:id`
- שנה רק טקסטים שמשתמש רואה (labels, placeholders, כותרות)

פקודה לחיפוש כל המקומות:
```bash
grep -r "יצרן" frontend/
grep -r "יצרנים" frontend/
```

## תיקון 2 — סיפור המייסדת (עמוד /about)

החלף את הטקסט הקיים בסקציית המייסדת בטקסט הבא:

```
כותרת: "היי, אני ספיר."

גוף טקסט:
"מייסדת מהמקור. בת 21, תוכניתנית בצבא, ולומדת רפואה תזונתית
אצל ד"ר גיל יוסף שחר.

התחלתי לשים לב שהכל סביבי רווי אוכל מעובד —
ואין מקום אחד שפשוט מראה לך איפה יש
אוכל אמיתי קרוב לבית.

כמו הרבה משפחות, התחלנו לחפש מקורות מזון מקומיים
ובריאים יותר. וגילינו שזה לוקח המון צעדים —
לשאול בקבוצות ווטסאפ, לגוגל, לחפש באינסטגרם...

עם כל הטכנולוגיה שיש לנו, זה לא אמור להיות
כל כך מסובך. אז מהמקור נולד."
```

## תיקון 3 — "הסיפור שלנו" (עמוד /about)

החלף את הטקסט הקיים:

```
כותרת: "הסיפור שלנו"

גוף טקסט:
"מהמקור נולדה מתוך צורך אמיתי — למצוא בשר grass-fed ליד הבית,
גבינות אמיתיות, לחם מחמצת שמישהו הכין בבית.

הכל היה מפוזר: קבוצות ווטסאפ, עמודי אינסטגרם, פליירים בסופר.
קשה למצוא, קשה להגיע, קשה לסמוך.

מהמקור שמה הכל במקום אחד —
פלטפורמה שמרכזת בתי עסק מקומיים, מגדלים קטנים,
ושכנות שמבשלות בבית. פשוט, נגיש, ואמיתי."
```

## תיקון 4 — Footer: "משפטי" → ניסוח אנושי

החלף את כותרת "משפטי" ואת הרשימה:

```
לפני:
  משפטי
  • תנאי שימוש
  • פרטיות  
  • דווח על בעיה

אחרי:
  שקיפות ואמון
  • תנאי השימוש שלנו
  • מדיניות פרטיות
  • משהו לא בסדר? דווחי לנו
```

## תיקון 5 — Micro-copy כללי לשיפור

החלף את הטקסטים הבאים בכל האתר:

| "אין תוצאות" | "לא מצאנו בינתיים — עדיין 🌱" |

| "בית עסק חדש" | "עסק חדש הצטרף 🌿" |
