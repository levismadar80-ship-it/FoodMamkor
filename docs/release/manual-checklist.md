# בדיקות בטלפון לפני גרסה — איך מסמנים, ומה בדיוק בודקים

> MEH-2896 (תוכנית העוגן, MEH-2892 §C.4).
>
> **הרשימה עצמה היא סעיף ד׳ ב-[RELEASE_CHECKLIST.md](../RELEASE_CHECKLIST.md),** והיא נשארת שם (ADR-028). הקובץ הזה לא מחזיק רשימה שנייה. יש בו רק שני דברים: איך מסמנים מהטלפון, ומה בדיוק עושים בכל שורה.

## איך מסמנים מהטלפון

קובץ md במאגר לא ניתן לסימון. **ה-PR של הגרסה** הוא המקום שבו מסמנים:

1. ה-thread שפותח את PR הגרסה בוחר מסעיף ד׳ רק את השורות **שהאזור שלהן השתנה בגרסה הזו**.
2. הוא מעתיק אותן לגוף ה-PR, תחת כותרת «ד׳ — לסימון מהטלפון», ושולח לספיר את הקישור.
3. ספיר פותחת את ה-PR באפליקציית GitHub ומקישה על התיבה של כל שורה שעברה.
4. כששורה **לא** עברה: לא מסמנים אותה, וכותבים תגובה ב-PR עם צילום מסך. ה-thread פותח באג.

**איפה בודקים:** ‏`staging.mehamakor.online`, מהטלפון. אם מופיע מסך התחברות של Vercel, מתחברים אליו פעם אחת.

## מה עושים בכל שורה

### מייל אמיתי ב-Gmail בנייד

אחת לכל סוג מייל שהשתנה בגרסה:

| מייל | איך מפעילים אותו | עובר כש |
|---|---|---|
| אימות כתובת | הרשמה חדשה ב-`/he/register` עם כתובת Gmail שלך + סימן `+`, למשל ‎`name+r1@gmail.com` | מגיע ל«ראשי» ולא לספאם או ל«קידומי מכירות», והקישור נפתח בטלפון ומאמת |
| איפוס סיסמה | `/he/forgot-password` עם אותה כתובת | מגיע, והקישור פותח את `/he/reset-password` |
| ברוכים הבאים | נשלח אחרי האימות | מגיע, והלוגו והטקסט נראים תקין |
| ניוזלטר | הרשמה ב-`/he/newsletter` | מגיע, וקישור ההסרה עובד |
| הרשמת עסק | הרשמה כעסק ב-`/he/register` | מגיע לבעלת העסק |

3. **עובר כש:** ההודעה מגיעה ב-WhatsApp, ואחרי הזנת הקוד הכרטיס מראה שהמספר אומת.
