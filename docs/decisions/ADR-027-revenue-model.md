# ADR-027 — Revenue model: base free forever, no transaction fees, trigger-gated premium

**Status:** Accepted (Council 12/07/2026 + Sapir ✓)

## Decision
1. הדף הבסיסי של בית עסק — חינם לעולם (דף עריכתי, תמונות, פרטי קשר).
2. אין עמלות עסקה. מהמקור לא נוגעת בכסף שבין לקוחה לבית עסק.
3. שכבת פרימיום אופציונלית (סיפור מורחב, גלריה, צילום) מותרת רק אחרי trigger:
   30+ עסקים פעילים וגם דוח פניות פר-עסק זמין. פרימיום לעולם לא משפיע על
   דירוג/חשיפה בלי סימון שקוף.
4. עמלת עסקאות — מחוץ לתחום. פתיחה מחדש רק ב-ADR חדש + ליווי משפטי +
   trigger נפח ימי איסוף (~4 אירועים/חודש, 50+ הזמנות).

## Supersedes
ניסוח ה-LOCK הקודם "No transaction fees ever" → "הדף הבסיסי חינם לעולם.
אין עמלות עסקה. פרימיום מסומן בלבד, מותנה-trigger (ADR-027)."

## Consequences
נוסח פניית הגיוס "חינם, בלי עמלות" נשאר אמת. מדידת פניות פר-עסק היא
תשתית-קדם לפרימיום (ראו MEH-1144 L3/L5).
